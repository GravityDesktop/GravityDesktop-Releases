# 引力桌面系统

Windows 11 x64 桌面伴随工作区。程序保存文件引用、视觉布局和关系数据，不移动、复制、重命名或删除真实文件。

簇团生长与“树冠羞避”的冲突裁决见 [`docs/GROWTH_RULES.md`](docs/GROWTH_RULES.md)。

## 构建

使用 Visual Studio 2022 打开 `GravityDesktop.sln`，选择 `Release | x64` 构建。

命令行构建：

```powershell
& 'C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe' `
  .\GravityDesktop.sln /m /p:Configuration=Release /p:Platform=x64
```

生成文件位于 `out\Release\GravityDesktop.exe`。

## 窗口与工作区

- 工作区固定贴合 Windows 可用桌面区域，不使用普通标题栏，也不能拖动或通过边缘任意缩放。
- 顶部控制条提供：创建核心、撤销、全局整理、设置、隐藏到托盘、全屏工作模式和退出。
- `F11` 在右侧工作区与全屏工作模式之间切换。
- 隐藏到托盘只隐藏界面，不结束进程；退出会先保存状态，再结束程序。
- 核心和文件节点接收鼠标；关系线、光晕、波纹和节点间空白区域保持鼠标穿透。空白处的点击、右键和框选由 Windows 桌面处理。
- 普通应用窗口可以覆盖引力桌面；Explorer 重启后程序会重新附着桌面宿主并重建交互区域。

## 核心与文件

- 顶部“＋ 创建核心”创建核心；新核心从预设主题色中选择颜色。
- 双击核心展开或收起。展开和收起只改变结构显示，不改写正式文件位置。
- 单击核心只选中核心：核心尺寸和位置不变，其他核心及文件不会因此变暗。
- 拖动核心会整体移动簇团；核心位置、布局和展开状态会保存。
- 双击文件使用 Windows 默认程序打开。
- 单击文件只选中一个文件，并增强该文件到所属核心的关系线。系统一次只保留一个核心或一个文件的选中状态。
- 鼠标悬停文件时只在原位置轻微放大图标，不触发布局或碰撞计算。信息卡显示完整文件名、路径和最近使用时间。
- 文件图标使用对应路径的 Windows Shell 图标；图片文件优先显示等比例缩略图。
- 文件短标题默认可见；长标题只在悬停时于标题区域内滚动，完整长文件名不会直接堆在图标下方。

## 拖放与文件关系

- 从 Windows 桌面或资源管理器把单个文件拖到核心主体：在该核心中创建普通视觉引用。
- 把单个外部文件直接拖到核心文件节点：先加入目标文件所属核心，再使用现有规则把它设为目标文件的子文件。整个操作原子提交，失败时不留下半成品引用。
- 把多个外部文件拖到文件节点会被拒绝；把多个文件拖到核心主体仍按现有普通导入规则处理。
- 外部文件已属于目标核心时复用现有引用；已属于其他核心时不会自动跨核心移动。
- 从引力桌面把文件 B 拖到文件 A：B 成为 A 的子文件。右键文件可“断开上层连接（保持独立）”。
- 有子节点的父文件迁移时，关系验证、容量检查、撤销和保存沿用现有事务规则。
- 所有拖放只修改引力桌面状态，不操作真实文件。

## 布局

- 每个核心最多关联 18 个文件。1 至 15 项使用标准容量；第 16 项按现有规则升级到 18 项容量；第 19 项会被拒绝。
- 紧凑双环使用内 5＋外 10；扩展双环使用内 6＋外 12。核心容量角标显示“当前数量/容量”。
- 图标和文字以 1080P 逻辑工作区为基准，按显示器 DIP、核心数量和密度设置响应式计算，不按 4K 物理像素重复放大。
- 图标、文字和安全距离构成完整占位盒。自动布局处理屏幕边界、核心边界和簇团间冲突。
- 同一核心内部，用户手动位置优先于自动碰撞；只有用户主动执行整理命令时，系统才重新整理该簇团。
- 不同簇团发生冲突时先移动相碰的文件到附近空白区域；只有核心本体距离过近时才移动核心。
- 内圈距离、外圈距离和整体旋转角度分别保存。关闭调节面板、取消选择、展开/收起和重绘不会累计应用距离倍率。
- “向空白处展开”保持核心位置不变，分析边界和相邻簇团后选择较空方向。

## 右键菜单

核心右键菜单：

- 展开核心或收起核心；
- 重命名核心（`F2`）；
- 核心外观设置；
- 恢复推荐布局、按圈均匀排列、单环均匀排列；
- 紧凑双环（内 5＋外 10）、扩展双环（内 6＋外 12）；
- 向空白处展开；
- 调整布局（布局调节面板和连线样式预设）；
- 锁定或解除布局锁定；
- 设为默认布局、恢复默认布局；
- 归档核心；
- 解散核心并把引用移至“未分类”；
- 移除核心及其全部视觉引用。

文件右键菜单：

- 打开、打开所在文件夹、在资源管理器中选中、查看完整路径；
- 固定、收藏、标记“进行中”；
- 重新定位；
- 断开上层连接并保持独立；
- 移除视觉关联。

“解散核心”和“移除核心及所有引用”都只处理引力桌面的核心或引用，不移动、不删除真实文件。

## 设置

- 顶部“设置”打开全局设置，不使用空白区域自定义右键菜单。
- 布局密度可选紧凑、标准、清晰。
- 动画强度可选关闭、简洁、标准、柔和；系统启用减少动画时会自动采用较克制的效果。
- 核心外观设置可调整核心颜色、尺寸、连线颜色、全局连线粗细和光晕强度。
- 连线粗细的“细线、标准、强调、自定义”预设和外观面板滑块共用同一个底层数值。

## 数据与安全

- 状态文件：`%LocalAppData%\GravityDesktop\state.json`。
- 当前状态格式版本为 15；旧状态缺少新字段时使用兼容默认值，不会自动创建测试核心或文件族。
- 保存时先写临时文件，再原子替换，并保留 `state.json.bak` 和历史快照。
- 启动和导入会验证状态结构、核心容量和文件关系；失败时保留原状态恢复保护。
- 文件夹按单个节点处理，不递归扫描。
- 使用频率只统计从本程序成功打开的次数。
- 程序不会执行真实文件移动或删除。

## 快捷键

- `Ctrl+Z`：撤销；
- `F2`：重命名选中的核心；
- `Delete`：移除选中的引力桌面对象；
- `F11`：切换右侧/全屏工作模式；
- `Esc`：退出当前临时操作或教程。

## 内置验证

```powershell
.\out\Release\GravityDesktop.exe --self-test
.\out\Release\GravityDesktop.exe --benchmark-layout
```

`--self-test` 和 `--benchmark-layout` 使用测试状态，不读取或写入正式 `state.json`。`--benchmark-layout` 在内存中生成 4 个核心、每核心 18 个文件引用，用于检查布局性能。
