# Gravity Desktop

Gravity Desktop is a Windows desktop organization and relationship workspace.

It helps users organize desktop files visually through cores and relationships while keeping the Windows desktop experience familiar.

## Status

Gravity Desktop is currently in early Alpha development.

## Downloads

Official Windows releases will be published on the GitHub Releases page.

No public release is available yet.

## Platform

- Windows 11
- x64

## Source Code

Gravity Desktop is currently closed source.

This repository is used only for official public releases, release notes, documentation, and downloads.
