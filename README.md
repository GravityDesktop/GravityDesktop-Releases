# 引力桌面系统

Windows 11 x64 原生桌面文件关系工作区。首版只保存视觉关联，不移动或删除真实文件。

簇团生长与“树冠羞避”的冲突裁决见 [`docs/GROWTH_RULES.md`](docs/GROWTH_RULES.md)。

## 构建

使用 Visual Studio 2022 打开 `GravityDesktop.sln`，选择 `Release | x64` 构建。

命令行构建：

```powershell
& 'C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe' `
  .\GravityDesktop.sln /m /p:Configuration=Release /p:Platform=x64
```

生成文件位于 `out\Release\GravityDesktop.exe`。

## 操作

- 使用 Windows 原生标题栏移动、最大化、最小化或关闭窗口；`F11` 可最大化/还原。
- 在空白处右键：创建核心、标准整理所有核心、分散核心、一键整理全部、撤销、复位视图、立即保存或打开数据目录。“一键整理全部”固定按“先分散核心、再让各簇团向空白处生长”的顺序执行。
- 从资源管理器拖入文件或文件夹：落到核心附近则加入该核心，否则进入“未分类”。
- 拖动核心：整体移动簇团。
- 拖动文件到另一个核心：只改变视觉归属。
- 在同一核心内普通拖动文件：吸附当前圆环并只改变角度；开启“自由布局”或按住 `Ctrl`/`Alt` 拖动时，才同时改变角度和半径。手动位置会保存并锁定，整理前必须由用户决定保留或重置。
- 双击核心：展开或收起。
- 双击文件：使用 Windows 默认程序打开。
- 单击核心：当前簇团以FLIP动画放大到1.32倍；再次单击同一核心即缩回。其他核心保留34%亮度、文件保留16%亮度。聚焦会尝试显示该核心全部18项；模板不足时，折叠项在临时高容量外环槽位出现，已有文件角度不变。
- 右键文件：打开、固定、收藏、标记进行中、重新定位或移除关联。
- 右键核心的“整理文件位置”提供：自动紧凑（默认）、单环平均排列、紧凑双环（5+10）、高容量双环（6+12）、向空白处生长、锁定当前布局、恢复上次布局；仍保留缩短/增加/恢复文件距离、解除手动位置、重命名、收起和删除等旧功能。
- 图标和文字以1080P逻辑工作区为基准，按当前显示器DIP工作区、核心数量和密度设置响应式计算；不会按4K物理像素重复放大。
- 文件使用对应路径的 Windows Shell 原图标；图片文件优先显示等比例缩略图。
- 每个可见文件在任何视图缩放下都常显静态短标题；只有鼠标悬停在长标题文件上时，完整名称才在裁切区域内慢速循环滚动。悬停浮层显示完整原名、路径和最近使用时间。
- 悬停只在文件原位置放大图标，不触发布局重排；信息浮层避开当前图标，但可覆盖其他节点。
- 每个核心最多关联18个文件。自动紧凑在6项以内使用单环、7至15项使用5+10骨架、16至18项使用6+12骨架；单环最多显示6项，紧凑双环最多15项，高容量双环最多18项。只有真实边界、文件名占位盒或树冠羞避无解时才折叠，折叠入口直接显示“已折叠 N 个”。加入、拖入或转移第19项会被拒绝。
- 内圈5项的目标半径为64 DIP，内圈6项为74 DIP。外圈半径按实际节点节距、外圈数量和内外圈最小安全距离计算，不再使用固定数值；双行标题会增加约10%。
- “向空白处生长”不随机散点，而是以5°步进旋转标准双环模板，按边界、其他核心、簇团占位盒和原角度变化评分；相同环境下结果完全一致。
- 图标、文字和安全距离组成完整占位盒；文件、核心和屏幕边缘都是硬障碍。
- 不同簇团的文件占位盒默认保留48px树冠间距；簇团碰撞只调整文件的径向距离，不推动核心。只有两个核心本体过近时才移动后处理的核心。聚焦是临时视觉状态：目标簇团可覆盖其他簇团图标，其他簇团不参与让位；缩回后恢复默认碰撞规则。
- 默认和聚焦状态保证核心、图标及名称完整留在窗口内。
- 选中项绘制在普通项之上，悬停项位于全局最上层。
- 拖动空白区域或按住鼠标中键：平移画布。
- 鼠标滚轮：在75%至150%之间缩放画布；所有档位都保留文件短标题，视图缩放不再隐藏名称。
- 空白处右键的“布局密度”可选紧凑、标准、清晰；“动画强度”可选关闭、简洁、标准、柔和。Windows关闭客户端动画时自动降为简洁。
- `Ctrl+Z`：撤销；`F2`：重命名选中核心；`Delete`：移除选中项。

## 数据与安全

- 状态文件：`%LocalAppData%\GravityDesktop\state.json`。版本9额外保存布局模板、核心布局锁定、模板旋转角、生长方向、文件实际角度和锁定状态。
- 保存时先写临时文件，再原子替换，并保留 `state.json.bak`。
- 文件夹按单个节点处理，不递归扫描。
- 使用频率只统计从本程序成功打开的次数。
- 程序不会执行真实文件移动或删除。

## 内置验证

```powershell
.\out\Release\GravityDesktop.exe --self-test
.\out\Release\GravityDesktop.exe --benchmark-layout
```

`--benchmark-layout`使用独立内存状态生成4个核心、每核心18个文件关联；不读取正式状态文件，任何菜单操作也禁止写入正式状态。
